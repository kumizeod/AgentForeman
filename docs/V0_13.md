# v0.13：Antigravity、立即终止、独立账号

本次只补这三项。官方客户端安装、官方登录和真实账号可用性，仍需在部署电脑上完成。测试中的模型回复会明确使用测试脚本，不能当作真实订阅验证。

## 1. Google AI Pro / Ultra 使用 Antigravity

「快速开始 → 添加连接 → Antigravity / Google AI Pro」。通过官方渠道安装原生 `agy` 客户端，点击打开登录终端，完成登录后添加并测试。模型可留空使用客户端默认值，也可填 `agy models` 列出的实际模型 slug。

适配的是官方 headless 协议：stream-json 单轮输入、stream-json 输出、JSON schema、plan 模式和有界执行时间；不会把 `gemini` 的参数原样发给 `agy`。仅接受一个 `SUCCESS` 终态及符合任务 schema 的产物；取消、未完成、错误和工具/子 agent 执行事件都不作为成功答案。使用 plan 模式和请求 terminal sandbox，但不把平台不支持的 sandbox 或客户端权限策略当成强制 OS 隔离保证。

旧 `gemini-cli` 入口保留并标注为企业 / 旧 API 兼容。**它不再作为 Google AI Pro/Ultra 的接入推荐。** 已有连接不会被自动换成另一个客户端或账号，需要用户明确选择 Antigravity，并按官方迁移提示完成登录。

Google 在 2026 年 5 月 19 日公告：免费用户和 Google AI Pro/Ultra 从 2026 年 6 月 18 日起转向 Antigravity CLI；部分企业许可和付费 API 的 Gemini CLI 接入继续保留。

## 2. 立即终止整个任务

任务详情增加红色 **「立即终止整个任务」** 按钮，覆盖需求澄清、合作、对抗、委员会、代码候选和夜间实验；原来的“停止后续阶段/轮次”仍是温和停止。

立即终止会：

- 持久保存终止意图，取消排队任务并禁止同一任务组继续入队执行。
- 对运行中的 worker 发出绑定当前 lease 的取消指令，写入 native supervisor 的取消标记。
- 本机托管 worker 直接收到取消标记；其他已升级 worker 在执行期间轮询取消指令。
- 终止客户端/API 请求进程及已知子进程，保存取消回执；晚到的结果不会被接受为成功产物。
- 对关联的已确认执行任务、委员会派生的本机实验继续传递终止意图。
- 显示“等待退出确认”或“执行节点已确认退出”。离线、失联或进程清理不确定的节点始终保持待确认，不能仅凭主席意见宣布停止。

终止意图先于进程创建检查；正在启动、重启恢复、已保存但尚未创建子任务的情况也不能绕过终止。已终止的澄清任务不能重新确认开工；需要重新创建任务。已有产物、日志和验证证据保留。

**立即终止不等于瞬间零消耗。** 网络延迟、系统进程清理和 API 服务端实现都会影响最终停止时间。已有 token 无法撤销；断开本机 API 请求不能证明服务商端的生成、后台任务或计费也已停止。因此 UI/API 明确保留服务商端状态为未知。CLI 自己脱离进程树或在远端启动的后台任务，也不能凭本机进程退出就宣称已取消。

远程 worker 必须升级到 v0.13 才能处理新的取消控制接口；旧版 worker 不能保证中途响应。暂停连接只停止新任务领取，不能替代这个按钮。暂停的执行节点仍可接收取消和提交结束回执。

## 3. 登录另一个 ChatGPT / Claude 账号

选择 Codex 或 Claude Code 后，界面新增 **「账号来源」**：

- **复用本机当前账号**：保留原来的接入方式。
- **登录另一个账号（独立配置）**：创建新的配置，再打开官方客户端登录终端。账号密码、验证码、SSO 或 MFA 都在官方登录页面/客户端完成；AgentForeman 不提供密码收集接口。

完成登录后，在账号下拉框中选择这个配置，点击添加并测试。后续登录、连接测试、worker 调用和重启恢复使用同一配置。多个模型可复用同一配置，串行共享资源；不同配置不是“已证明不同订阅额度”，实际登录哪个账号由用户在官方页面选择。

Codex 使用独立 `CODEX_HOME`；Claude Code 使用独立 `CLAUDE_CONFIG_DIR`。不会复制、覆盖或退出默认客户端账号。独立会话去掉可能抢占该客户端认证的环境 API key、OAuth token 和第三方路由设置；只在子进程环境里设置目录，不更改启动终端的全局环境变量。

账号配置和官方客户端生成的认证文件位于项目的 `.foreman/accounts/`，被 Git/实验快照排除；POSIX 上目录设为仅当前用户访问。Codex 的独立配置使用官方文件认证存储和 ChatGPT 登录限制；Claude 使用 claude.ai 登录限制。文件中的 OAuth 凭据由官方客户端写入，属于敏感文件，不要分享整个目录。Windows 仍依赖当前用户目录的 ACL，不能把项目放进不受信任者可读的共享目录。API 密钥原有的系统凭据库存储方式不变。

这里支持的是 ChatGPT/Codex 和 claude.ai 订阅登录，不把不同 Claude Console 无 API-key 会话、企业管理限制或第三方登录方式伪装成已验证隔离。客户端版本或企业策略不支持时，登录/连接测试应明确失败，不能回退成默认账号。

## 验证范围

最终代码 `709f3ab` 的 [CI](https://github.com/kumizeod/AgentForeman/actions/runs/40719768093) 已通过全部 9 个 Windows/macOS/Linux × Python 3.11–3.13 组合，每组运行 220 项测试（按平台跳过不适用项），以及 18 组浏览器流程。[固定版本验证记录](../evidence/v0.13-validation.json)。

新增测试覆盖：Antigravity 实际 subprocess 协议和失败终态；独立账号的子进程环境、默认账号不变、元数据不泄露凭据；真实 HTTP 取消控制、暂停节点取消、忽略 SIGTERM 的子进程清理、挂起 API 连接关闭、离线节点保持未确认、迟到结果拒收和启动/恢复竞态。浏览器测试覆盖连接选项、官方登录路由、独立账号选择、立即终止按钮与离线回执展示。

真实 ChatGPT、Claude、Google 或中转站的账号权限、订阅和计费，不由测试脚本证明。请在各自部署电脑登录后执行实际连接测试。
