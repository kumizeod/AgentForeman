# v0.14：任务、订阅、用量，三个页面

## 日常操作

1. 打开「订阅与模型」→「添加连接」，选择本机订阅、独立账号或 API / 中转站，完成登录并测试。密码和验证码仍在官方登录流程中输入。
2. 回到默认首页「任务」→「新建任务」。与主席澄清目标、资料、交付物和验收方式，核对完整约定、分工与预算后确认开工。
3. 首页左侧选任务，右侧看对话、执行阶段、当前产物、独立验证与待验证问题；「立即终止整个任务」保留逐节点退出确认。
4. 「用量」查看最近 24 小时 / 7 天 / 30 天的已上报 tokens、连接占比和任务明细。点击已关联的任务可回到首页。

已确认的澄清任务和派生执行任务在首页合为一条，统计也合并两阶段的调用。独立创建的委员会、代码候选和夜间实验仍可查看。页面底部的「高级工具」保留夜间实验、手动分工、Codex 额度窗口与环境诊断；日志、导出、归档和原有操作仍在详细视图中。

## 目标占比与实际占比

「订阅与模型」可按连接保存整数目标占比，合计必须为 100%。保存时检查版本和连接集合，其他窗口修改后不能悄悄覆盖；可放弃修改重新加载。

- 已保存的 0% 连接不参与新快速任务的自动分工；仍可用于高级工具中明确指定的任务。
- 自动分工首先按非零偏好排序，并将各连接的目标占比提供给主席。主席还需满足独立角色、可用连接与能力要求，分工理由在确认前可查看。
- **这是分工偏好，不能保证精确 token 占比，也不是硬预算或余额调度。** 主席可能偏离比例，任务长度和重试也会改变实际消耗。系统没有通过填充调用来凑比例。
- 修改只影响新任务，不改变已确认任务。合作模式至少需要四个可用且非零的连接，对抗模式至少三个。多个连接如果使用同一账号，仍共享原有串行资源；不能认为获得了多份独立额度。

## 用量数据与持久化

执行节点读取本次受监督调用自己的结构化输出，不扫描个人客户端登录目录或其他会话。调用完成时，通过已有认证的 worker 接口上报固定字段：provider、model、输入 / 输出 tokens、完整性与来源；不上传原始日志、提示词或密钥。

协调器按真实 lease 验证归属，以 lease 为唯一键写入 SQLite。成功、失败、额度重试、取消后晚到的调用只要有实际用量回执就计入；重放同一上传不会重复累计。取消后的产物仍被拒收，用量可以保留。旧 worker 的无用量请求仍兼容，显示未知；远端需要升级才会开始上报。

连接测试也消耗模型用量，单独归入「连接测试」，关联实际连接。旧的夜间 Codex 实验从已有 `turn.completed` 日志读取；不能确认原订阅账号的旧调用单独标为历史连接，不归到当前账号。旧版本未保存的调用、任务和账号关联不会凭空补齐。

统计解析：

| 来源 | 采用的记录 | 未返回时 |
| --- | --- | --- |
| Codex | `turn.completed.usage`；缓存输入已属于输入，不再相加 | 未知；不完整日志保留部分记录标记 |
| Claude Code / Anthropic API | 输入、缓存读取、缓存创建和输出计数；三种输入相加 | 未知 |
| OpenCode | `step_finish.part.tokens`；输入含独立 cache 读写项，输出不重复加 reasoning；有 ID 的重复步骤去重 | 未知 |
| OpenAI 兼容 API | `prompt_tokens` 与 `completion_tokens` | 未知 |
| Antigravity / 旧 Gemini | 当前未实现其用量格式解析 | 未知，不按字符数估算 |

API 在验证答案之前保存 allowlist 用量，因此“模型回复不符合任务协议”也能保留已返回的消耗。断开连接或被终止而没有收到计数时，保留未知。

占比分母只包含已上报的输入 + 输出 tokens，页面同时列出未知和部分记录的调用数。实际总消耗可能更高；这不是订阅剩余额度、账单或模型能力比较。时间范围按回执记录时间筛选，历史实验按进程启动时间筛选；跨时段调用不做不可验证的分摊。这里的“近期”是滚动时段，不是自然日/月账单。

`GET /api/workspace`、`GET /api/token-usage?days=7`、`GET /api/preferences` 均为只读，不启动模型调用。偏好修改继续使用原有本机 capability、Host、Origin 检查。

认证、服务商端取消与计费边界仍见 [v0.13](V0_13.md)。本地自动化使用脚本化模型回复和真实 HTTP、原生进程、训练、检查及归档；真实订阅登录、模型质量和账单需在部署机器验证。

格式依据：[Anthropic 缓存计数](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)、[OpenCode Inference 计数说明](https://opencode.ai/v2/docs/console/api/inference)。兼容版本不返回这些字段时保持未知。
